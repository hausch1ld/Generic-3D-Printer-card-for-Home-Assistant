# Generic 3D printer card for Home-Assistant
This is a dashboard card for 3D printers with customizable entities and images

This is a **very first version** of the dashboard card. It's tested with [@Nino6689](https://github.com/Nino6689)s impressive [hass-anycubic](https://github.com/Nino6689/hass-anycubic) integration but the card should be compatible with many 3D printers with entities for each function.

Current features:
- Select an image of your 3D printer as background
- Select an image of your AMS/ACE for the upper multi filament system
- Define entities for every function shown in the screenshot
- Switch between model image and livestream
- Buttons for nozzle and bed temps and fan control 

In the next days I'm looking forward for some of these features:
- Frontend editor
- Disable elements
- Rearrange elements
- additional features

Feel free to send me your wishes and ideas.
